# Steward workspace. Scoped to this directory so the parent project's own
# ignore rules stay untouched.
#
# `logs/` and `logs-archive/` are ignored because .eval files are large
# archives, outputs rather than source, and shared through a log store rather
# than through git. Ignored is not the same as disposable: they are DURABLE,
# and only `.steward/` is safe to delete.
#
# `.env` holds the credentials a scheduled tend and its workers read. Steward
# suggests putting them there when you arm a timer, so it is ignored here to
# make sure that suggestion is not also a way to commit your API keys.
#
# The two logs are machinery rather than record — whether Steward worked, not
# what it found. They are appended to every interval, and a file that changes
# on a cadence has no business in a diff.
